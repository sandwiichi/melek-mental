# Melek Mental 🧠✨

Aplikasi Kesehatan Mental Gen Z — SPA dengan AI Journaling, Konseling Psikolog, Dashboard, dan Mental Journey Analytics.

## 🚀 Live

🔗 **https://sandwiichi.github.io/melek-mental/**

## 📁 Struktur

```
melek-mental/
├── index.html     ← Full SPA (all screens built-in)
├── css/style.css  ← Custom styles (shared)
├── js/script.js   ← JavaScript
└── README.md
```

## 🛠️ Fitur

- 🏠 Landing page
- 🔐 Login/Register
- 👩‍⚕️ Direktori Psikolog + Booking Drawer
- 📊 Dashboard (Mood Tracker, To-Do, Jadwal)
- 🤖 AI Journaling Wizard (5 steps)
- 📈 Mental Journey Analytics
- 📱 Mobile responsive
